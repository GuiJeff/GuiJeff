# 👩🏻‍💻 Guilherme Almeida

**`Software Developer & QA | Game dev with Unity`**

Hi, I’m Guilherme, a software developer with 6+ years of experience in ERP systems. I started in customer support, moved into QA, and then into development, so I understand a product from the user’s problem all the way to the code. I work mainly with C#, SQL Server and JavaScript, and I care about writing software that is maintainable and well tested. I also have a degree in Digital Games Technology and enjoy building games with Unity in my free time.
